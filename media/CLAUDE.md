# iEsports Media Pipeline

## Purpose
Extract highlight clips from tournament VODs, add subtitles with Discord speaker names,
and format for YouTube (16:9) and Instagram Reels (9:16).

## Running
Each script runs independently in order:
```
npm run download    # Step 1: Download from YouTube
npm run frames      # Step 2: Extract + crop frames
npm run timeline    # Step 3: Claude Vision → round timeline
npm run speakers    # Step 4: Claude Vision → who's speaking
npm run transcribe  # Step 5: Whisper → subtitles with names
npm run trim        # Step 6: FFmpeg → highlight clips
npm run reels       # Step 7: FFmpeg → 9:16 Instagram format
```

## Prerequisites
- brew install yt-dlp ffmpeg
- pip install openai-whisper --break-system-packages
- ANTHROPIC_API_KEY in .env

## Code Conventions
- TypeScript, strict mode
- Each script is standalone (01-download.ts through 07-make-reels.ts)
- Console logs: [DOWNLOAD], [FRAMES], [TIMELINE], [SPEAKERS], [TRANSCRIBE], [TRIM], [REELS]
- All paths via path.join(), config in src/config.ts
- FFmpeg commands logged before execution
- No frontend, no CSS, no Tailwind — CLI pipeline only

## Key Files
- data/timeline.json — round-by-round timestamps (generated by step 3)
- data/speakers.json — speaker detection (generated by step 4)
- data/highlights.json — which rounds to clip (created manually or auto-detected)

## Video Layout (1920x1080) — Calibrated
- Scoreboard: x=420, y=15, w=1080, h=110
- Discord Left (Team 1 - Muth rajya): x=0, y=330, w=250, h=350
- Discord Right (Team 2 - Radiant Reapers): x=1660, y=330, w=260, h=340
